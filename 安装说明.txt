CanvasMind 客户版 · 安装与使用说明 (v2.2)
==========================================

一、本版本新特性 (v2.2)
  - 多画布并行: 可同时开多块画布, 每块画布有独立的 AI 对话框与会话记录
  - 对话框顶部块状按钮一键切换画布, 实时显示每块画布的运行状态(转圈=运行中/黄色=疑似停滞)
  - 每块画布(含新建画布)都带完整导航与平台组件
  - AI 能力: 智能对话 / 生图 / 生视频 / 文件分析 / 百秒短剧 / 技能中心

二、系统要求
  - Windows 10/11 64 位
  - 内存 >= 8GB, 磁盘剩余 >= 3GB
  - 无需安装 Python / Node (安装包内含全部运行时)
  - 推荐安装 Chrome 或 Edge 浏览器

三、安装步骤
  1. 双击 CanvasMind-setup.exe 安装 (SmartScreen 提示时选「更多信息」->「仍要运行」)
  2. 安装完成勾选「运行 CanvasMind」, 之后随时双击桌面「CanvasMind」图标
  3. 浏览器自动打开 http://127.0.0.1:6205 —— 注册账号即送试用积分, 登录即用

四、日常使用
  - 启动: 双击桌面「CanvasMind」(服务已在跑则直接打开页面, 不会重复启动)
  - 停止: 安装目录下 stop.bat
  - 管理后台: http://127.0.0.1:6205/admin (管理员 you / 51682688, 登录后请改密)
    · 积分价格 / 试用积分 / 充值审核 / 浏览器池
    · AI 中转 Key 配置: 可将 AI 消耗切换到指定的 66AI 中转 Key (留空=出厂默认)

五、服务与端口 (config.bat 可改, 需与程序内置一致)
  - 6205  gateway 网关 (登录/注册/积分/门户, 对外入口)
  - 6206  Toonflow 画布内核 (无限画布 + AI 节点 + 右侧 AI 对话框)
  - 6216  bridge 引擎 (大模型 OpenAI 兼容接口 /v1, 生图/生视频中转)
  - 6301-6350  多用户实例端口池 (每个在线用户占用一个)

六、目录结构
  app\Toonflow-app\      画布前后端 (bun 运行时 + build 产物 + data 配置)
  runtime\python\        内嵌 Python 运行时 (无需安装 Python)
  templates\              网关页面模板
  logs\                   全部服务日志 (排错先看这里)
  uploads\ videos\        用户上传素材与生成视频

七、常见问题
  1) 双击图标没反应/打不开页面: 先看 logs\gateway.log; 杀毒软件拦截 python/bun 时请加白名单
  2) 端口被占用: 改 config.bat 中端口后, 需同步联系服务商 (程序内置默认端口一致)
  3) AI 生成失败: 检查网络; 连续失败联系服务商确认中转额度
  4) 数据备份: app\Toonflow-app\data\workspaces (画布数据) + canvas_auth.db (账号积分)

八、卸载
  - 先运行 stop.bat 停止服务, 再用「设置->应用」或开始菜单卸载入口卸载
